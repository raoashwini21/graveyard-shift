# Moonbrew Coffee Co. (demo site)

A fake coffee shop for demoing Graveyard Shift. Every problem on it is planted on purpose:
missing careers and signup pages, a typo link, a dead GitHub link,
an expired event, a 2021 copyright, a page with no title, one with no description, a redirect chain
(the http "Order online" link) and a link to Mint, which shut down and now redirects elsewhere.
